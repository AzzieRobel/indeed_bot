# Template Placeholder Reference

This document describes the placeholder schema used by the autogenerated ATS-friendly templates.

## Resume Templates

### `resume_classic.docx`
| Placeholder | Description |
|-------------|-------------|
| `${FULL_NAME}` | Candidate full name |
| `${PROFESSIONAL_TITLE}` | Target job title |
| `${CONTACT_BLOCK}` | Email, phone, location, portfolio links |
| `${SUMMARY}` | Professional summary paragraph |
| `${CORE_SKILL_1}` ... `${CORE_SKILL_4}` | Individual core skill bullet slots |
| `${EXPERIENCE_SECTION}` | Injected experience entries and bullets |
| `${EDUCATION_SECTION}` | Education history |
| `${CERTIFICATIONS_SECTION}` | Certifications or licenses |

### `resume_modern.docx`
| Placeholder | Description |
|-------------|-------------|
| `${FULL_NAME}` | Candidate full name |
| `${TAGLINE}` | Short positioning statement |
| `${CONTACT_BLOCK}` | Contact information |
| `${PROFESSIONAL_PROFILE}` | Summary/profile paragraph |
| `${TECH_STACK}` | Technical skills |
| `${SOFT_SKILLS}` | Soft skills |
| `${EXPERIENCE_SECTION}` | Experience entries |
| `${PROJECTS_SECTION}` | Highlighted projects or achievements |
| `${EDUCATION_SECTION}` | Education details |

## Cover Letter Template

### `cover_letter_standard.docx`
| Placeholder | Description |
|-------------|-------------|
| `${DATE}` | Current date |
| `${HIRING_MANAGER}` | Hiring manager name or placeholder |
| `${COMPANY_NAME}` | Company |
| `${COMPANY_ADDRESS}` | Company location |
| `${OPENING_PARAGRAPH}` | Opening paragraph |
| `${BODY_PARAGRAPH_1}` | Body paragraph emphasizing fit |
| `${BODY_PARAGRAPH_2}` | Optional second body paragraph |
| `${CLOSING_PARAGRAPH}` | Closing paragraph |
| `${SIGN_OFF}` | Closing phrase |
| `${FULL_NAME}` | Candidate full name |

Each placeholder maps to dynamic content generated during resume or cover letter creation. Do not remove the `${...}` tokens; downstream code replaces them while preserving styles.
